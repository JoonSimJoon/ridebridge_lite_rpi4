# RideBridge Lite 소개 영상 시나리오

권장 길이 3분 10초, 화면비 16:9, 기사 1명·외국인 승객 1명·내레이션 1명 기준이다.
핵심 메시지는 “말이 통하지 않아도 즉시 확인하고 안전하게 이동한다”이다.

## 촬영 전 준비

- Raspberry Pi 4, HDMI 모니터, 회로도대로 연결한 버튼 3개와 공통 캐소드 RGB LED
- Pi 4의 3.5mm 잭에 이어폰 또는 스피커 연결
- 기사 화면 `http://localhost:5000/driver`
- 같은 Wi-Fi의 휴대폰에서 `http://<Pi-IP>:5000/passenger`
- 승객 언어 `English`, 기사 운행 상태 `주행`
- 브라우저 TTS 음량과 3.5mm 출력 사전 확인
- 자유문장 번역 시연용 인터넷 연결 확인
- 촬영 직전 앱을 재시작하고 대화 로그를 비운 상태로 준비

스마트폰을 HTTP IP 주소로 접속하는 현재 시연에서는 브라우저 STT 대신 텍스트와
빠른 문장을 사용한다. 기사 쪽 3.5mm 잭도 출력 전용이므로 마이크 녹음 장면으로
연출하지 않는다.

## 실제 화면에 입력할 시연 문장

승객 빠른 문장:

> Please drop me off here.

기사 자유 입력:

> 곧 도착합니다. 안전벨트를 확인해 주세요.

승객 화면 예상 결과:

> We will arrive soon. Please check your seat belt.

번역 서비스 결과는 시점에 따라 문구가 조금 달라질 수 있으므로 촬영 전에 실제
출력을 확인한다. 번역 문구를 정확히 고정해야 하는 장면은 `data/phrases.json`의
검수된 빠른 문장을 사용한다.

## 촬영·편집 체크리스트

- LED는 주변광을 낮추고 노출을 고정해 파랑/초록이 하얗게 날아가지 않게 촬영
- 모니터 촬영은 셔터 속도를 1/60초부터 조절해 플리커 제거
- 휴대폰 화면은 가능하면 화면 녹화본을 사용하고, 손 동작 숏과 편집으로 합성
- 3.5mm TTS 소리는 Pi 화면 녹화와 별도 라인/현장 녹음 후 싱크
- GPIO 버튼을 누르는 손, LED 변화, 상대 화면 결과를 한 동작당 3컷으로 확보
- `STT not-allowed` 오류 화면은 촬영하지 않고 텍스트/빠른 문장 fallback을 시연
- 차량 내부 촬영은 반드시 정차 상태에서 진행하고 “연출된 장면” 자막 삽입
- 엔딩 전에 `/api/health`에서 `gpio_available: true`와 백엔드를 확인
